# 眠川 VRC 热上传使用说明

本说明对应当前仓库中的 Windows 本地版。无需 Unity、卡密或自建授权服务器，但登录、下载和上传仍需要连接 VRChat。请只处理你拥有或已获授权使用的资源。

## 1. 首次运行与登录

1. 将完整目录解压到可写的位置，保留 `MianchuanUploader.exe`、旁边的 DLL 和整个 `tools/` 文件夹。
2. 确保电脑安装 .NET Framework 4.8，运行 `MianchuanUploader.exe`。
3. 点击左下角“账号管理”，填写 VRChat 用户名或邮箱及密码，点击“登录”。这里不是 Steam 登录窗口，不接受 Steam 账号密码来代替 VRChat 凭据。
4. 需要两步验证时，填写账号对应的邮箱验证码或验证器动态码，再点击“验证并登录”。不要默认所有验证都会发送邮件。
5. 显示“已连接 VRChat”后，进入工作空间。上传权限仍受账号状态与 VRChat 服务规则限制。

需要代理访问 VRChat 时，请先确认系统代理能连接 VRChat API 和文件下载／上传服务。不要短时间反复点击登录，以免触发限流。

## 2. 上传模型

1. 点击“01 模型上传”，选择一个 `.vrca` 文件，也可以把单个 VRCA 拖入模型表单。
2. 确认“模型名称”，按需填写“简介”。选择文件时名称会按文件名自动填入，可在之后修改。
3. 如需自定义封面，点击“更换封面”，选择 PNG、JPG 或 JPEG。留空时上传使用工具默认封面。
4. 确认发布状态。“私有”为默认值；只有确认要公开时再选择“公开”。
5. 可先点击“预检查”查看本地检查结果；点击“开始上传”后，任务会加入队列并自动开始。
6. 到“04 上传队列”查看处理、传输和服务器检测结果。最终显示“成功”后，可使用“复制 ID”获取 Avatar ID。

建议封面不超过 **3 MiB**，使用能正常打开的 PNG 或 JPEG。当前这份本地版没有封面 3 MiB 硬限制，不会自动缩小超大图片；封面上传失败也会导致整个任务未完成。

当前模型预检查对输入文件设置 **600 MiB** 的本地准入上限，对最终 PC 上传包检查 **200 MiB** 下载大小与 **500 MiB** 展开大小。输入小于 600 MiB 不代表最终一定合规；外层压缩不会减少资源展开大小。这些是当前代码的检查值，不是对 VRChat 后续规则的保证。

当前模型页面是选择单个 VRCA 创建上传任务，不提供模型 PC / Quest 双文件配对输入。

## 3. 上传世界与双端世界

1. 点击“02 世界上传”，选择 PC 端 `.vrcw`，PC 文件是当前界面的必选项。
2. 有同一世界的 Quest 端 `.vrcw` 时，在 Quest 一栏选择它；文件选择器也支持一次选两个平台文件。检查最终填入的路径及平台提示，不要仅凭文件名认定平台。
3. 只传 PC 时保持 Quest 路径为空；移除 Quest 文件可直接清空该路径。只有 Quest 文件、没有 PC 文件时，不能通过此界面创建独立 Quest 任务。
4. 填写世界名称，按需更换封面，确认“私有”或“公开”。
5. 新建世界时，“更新现有世界 / World ID”留空；更新自己的现有世界时，填写完整 `wrld_...` ID，操作前确认登录账号具有更新权限。
6. 点击“开始上传”，在上传队列等待结果。双端任务先完成 PC，再将 Quest 上传到同一个 World ID，不会把两份文件合成为一个包。

PC 成功但 Quest 失败时，队列会显示部分完成。先记录 World ID 和完整日志，检查失败平台，不要把这次任务当作双端成功。需要重做时可在世界页面填写同一 World ID、重新选择两端文件；当前页面不是独立的“只重试 Quest”入口，重新开始可能再次上传 PC。

### 更新世界时使用 worldSignature

填写 World ID 后，同一页面内才会显示“PC 签名文本文件（可选）”；选择 Quest 文件后还会显示对应的 Quest 签名输入。

1. 如果已有与目标世界及该平台构建相匹配的签名，将签名的纯值保存为 UTF-8 `.txt` 文件，不要包含 `worldSignature=`、JSON 字段名或引号包装。
2. 在对应平台的签名文本一栏点击“选择”，选中这个文件。文本须非空，不超过 1 MiB。
3. 更换 World ID 或世界包后，重新检查签名选择；界面会清除相关旧选择，避免误用。

没有签名时可不选，但这不代表所有世界都能无签名上传。工具不会从世界 ID 推导出有效签名，也不会因为填入任意文本就保证通过官方验证。

## 4. 扫描文件夹并批量上传

1. 点击“03 文件夹扫描”，选择包含模型和世界的目录，点击“开始扫描”。工具会遍历子文件夹，识别结果陆续显示在当前窗口。
2. 在模型与世界分区检查文件、封面和平台。普通版与面捕版 VRCA 会独立列出，不会仅因同目录就合并为一个模型。
3. 工具会尝试把同一世界的 PC / Quest 文件配对；不同名称也可能依据世界 ID 等线索匹配，但同目录不代表一定是同一世界。上传前核对两条实际路径和“仅 PC”“PC + Quest”等提示。
4. 封面匹配取自资源所在目录；只有一张图片时使用它，多张时参考文件名相似度。匹配不准时点击该条目的“封面”手动调整。
5. 简介预览依次尝试同名 `.txt`、`简介.txt`、`description.txt`，只用于辅助浏览，不应把预览文本视作完整的世界上传表单。
6. 勾选需要处理的条目，点击“上传已选”，也可点击单条“上传”。“全选”“全不选”用于调整勾选范围。

扫描创建的任务使用匹配到的名称与封面，但简介和发布状态取自“模型上传”页当前填写的值，不会把每条扫描简介直接作为上传简介；扫描世界也不沿用世界表单的 World ID 或签名文本。批量操作前先确认模型页的发布状态为你期望的值。需要更新已有世界或分别设置元数据时，使用对应的单文件上传表单。

首次识别较大世界可能需要时间。可点“停止扫描”保留已显示结果，点“任务队列”切换页面，再从侧栏返回扫描。结果和平台识别会缓存；增删或替换文件后应重新扫描，检查缓存结果是否仍符合当前文件。

为减少误配，建议一个子文件夹只放一个模型的相关版本，或一个世界的 PC / Quest 文件及其封面；不相关的世界分开存放。文件名中的 `PC`、`Quest` 标记只是辅助信息，不会把 PC 包转换成 Quest 包。

## 5. 批量下载模型、封面与简介

1. 登录后点击“05 模型下载”，等待加载；列表未更新时点击“刷新”。列表内容由当前账号和接口实际可访问的数据决定，不是任意模型 ID 下载器。
2. 使用搜索框查找模型，点击一行可查看封面和简介。
3. 勾选左侧复选框选择多个模型，也可点击“全选”或“取消选择”。存在勾选项时以勾选项为准；否则使用当前高亮选中的行。
4. 点击“下载选中模型”，选择输出文件夹，等待完成汇总。

每个模型创建一个独立子文件夹，通常包含：

```text
输出文件夹/
  模型名称_v版本/
    模型名称_v版本.vrca
    模型名称_v版本.png
    模型名称_v版本.txt
```

PNG 是下载到的封面转换结果；原封面不可用时会生成默认封面，并在结果中说明。只有账号数据里确有非空简介时才生成 TXT，TXT 包含名称及可取得的 ID、发布状态和简介。已有同名目录时会添加编号，不直接覆盖原目录。

## 6. 队列、日志与多账号

- “04 上传队列”按任务显示总进度和当前阶段。“停止”请求取消任务，“移除”用于清理已结束的任务卡，“日志”查看对应任务详情。
- 文件数据传完不等于全部上传完成，后面可能还有封面、记录提交或服务器安全分析。以任务最终状态为准，不要只看某一步到达 100%。
- 右上角“打开日志目录”打开程序目录下的 `_runtime/logs/`。反馈问题时提供对应时间的完整日志、失败阶段和文件基本信息，不要只截一段进度。
- 日志对部分凭据字段有脱敏，但仍可能包含资源 ID、账号信息、本地文件名和路径。分享前自行检查，不要提供账号会话目录。
- 同一窗口切换账号前先停止上传或等待下载完成，再到“账号管理”点击“退出账号”。活动任务期间会阻止退出。
- 再运行一次程序可开启独立账号窗口。第一个窗口使用持久会话，后开的窗口使用临时独立会话，正常退出后清理；不要假定多个窗口都会永久记住各自账号。多开仍共享电脑资源、网络和平台限流。

## 7. 常见问题

| 现象 | 先检查什么 |
| --- | --- |
| 启动提示缺 DLL 或找不到处理程序 | 是否解压了完整目录，DLL、`tools/` 是否被移动或被安全软件隔离；不要随意关闭系统防护 |
| 登录返回 401 | VRChat 用户名／邮箱、密码、账号状态及验证步骤；不能仅凭 401 判断一定是密码错误 |
| 登录或接口返回 429 | 已被接口限流，停止反复尝试，按服务提示等待后再试；网页登录成功不保证另一条接口没有限流 |
| 超时、连接关闭、502 | 检查网络、系统代理及服务端状态；这些现象不等于文件损坏或账号密码错误 |
| 封面阶段失败 | 将图片转换为正常 PNG／JPEG、控制在建议的 3 MiB 内，再查看图片请求的具体错误 |
| 本地处理很慢 | 大包需要解压与 LZMA 重压，检查剩余磁盘空间、CPU、磁盘活动及日志；单凭进度暂时不动不能断言卡死 |
| PC 成功但 Quest 失败 | 保存 World ID，查看 Quest 阶段日志；PC 成功不会自动证明双端均成功 |
| 安全分析失败或 403 | 查看具体请求地址、响应和分析状态；不能把任何 403 都当成安全分析判定失败，也不能靠反复重试保证通过 |
| 下载没有简介 TXT | 只有接口返回非空简介时才生成 TXT，不代表模型文件下载失败 |

遇到问题先保留源文件。不要为排错删除整份个人缓存、改原包或持续重复创建上传记录。工具无法保证把损坏、缺资源或不受支持的包修复成有效资源。
